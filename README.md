# DSA with C++

A structured collection of my **Data Structures and Algorithms (DSA)** course practice, implementations, and assignments using **C++**.

This repository is organized by **DSA topic and lecture**, making it easy to track my learning progress and revisit concepts throughout the course.

---

## 📚 Topics Covered

- Fundamentals
- Arrays
- Strings
- Linked Lists
- Stack
- Maps & Sets
- Sorting Algorithms
- Sliding Window
- Heaps
- Binary Trees
- Graphs
- Greedy Algorithms
- Dynamic Programming
- And more as the course progresses

## 💻 Compiling and Running

### Compile

Using G++:

```bash
g++ filename.cpp -o program
```

### Run on Windows

```bash
program.exe
```

### Run on Linux / macOS

```bash
./program
```
